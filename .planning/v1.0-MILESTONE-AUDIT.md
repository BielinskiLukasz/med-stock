**Phase:** 3  
**Requirement:** "User can trigger a 'Sync Now' flow that guides them through exporting to / importing from a shared OneDrive folder — enabling two household members to share one inventory across their devices."  
**Delivered:** `SyncInstructions.tsx` — static 4-step paragraph text. No trigger button, no state machine.  
**Evidence:** REQUIREMENTS.md marks `[ ] Pending`. UAT Test 12 decision: *"Add triggered Sync Now flow to backlog. Static instructions are not sufficient — DATA-04 remains open as a backlog item."*  
**Backlog:** B-002 (Interactive Guided Sync Flow)

### DATA-02 — Merge vs. full replace

**Phase:** 3  
**Requirement:** "User can import a JSON backup file to restore or merge inventory." (text says "restore or merge")  
**ROADMAP SC-2:** "existing records are merged with last-write-wins conflict resolution" (more specific)  
**Delivered:** `importFromJSON` does a full replace (clear + bulkAdd all 3 tables, D-47).  
**Evidence:** UAT Test 13 decision: *"Merge was always the intent. Full replace (D-47) is a gap, not a design choice. BACKLOG.md B-003 captures the work to implement proper merge with last-write-wins."*  
**Note:** Requirement text "restore or merge" makes "restore" alone technically satisfying. Marked partial because the ROADMAP SC and UAT owner explicitly called this a gap.  
**Backlog:** B-003 (Merge-Based Sync)
