    3. try:
       a. const result = await parseCSVFile(file)
       b. if (result.errors.length > 0 && result.data.length === 0): toast.error("Failed to import: No data found in spreadsheet") and return (exact UI-SPEC CSV Empty File Error case)
       c. setParseResult(result)
       d. Build initial mapping: every header in result.meta.fields (or Object.keys(result.data[0] ?? {})) maps to SKIP_VALUE. setColumnMapping(initialMapping).

    1. if (!parseResult) return

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User-selected CSV file → Papa Parse | File content is untrusted; may be malformed, oversized, or adversarially crafted |
| Parsed CSV rows → db.medicines.bulkAdd | Mapped row data enters the DB without schema validation |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-05 | Tampering | mergeCSVRowsToMedicines / bulkAdd | medium | mitigate | mergeCSVRowsToMedicines applies per-row validation: rows with empty/missing 'name' are skipped (skippedCount tracks them). quantity fields are parsed via parseFloat with NaN check — non-numeric values become null rather than causing type corruption. All fields other than name are nullable so malformed values degrade gracefully to null. |
| T-03-06 | Denial of Service | parseCSVFile with very large file | low | accept | Papa Parse processes CSV files in a streaming fashion internally. For a household medicine inventory app, expected CSV sizes are at most hundreds of rows. Enforcing a row count limit would reduce usability for users migrating from large spreadsheets. The risk is accepted. |
| T-03-07 | Information Disclosure | CSV preview in browser | low | accept | The CSV preview renders row data in the DOM, which is visible to anyone viewing the screen. This is an inherent property of the preview feature and cannot be mitigated without removing the preview — which is required by D-53. Accepted by design. |
</threat_model>
