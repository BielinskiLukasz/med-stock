  <behavior>
    Input type: { id: number; name: string; category: string | null }[]
    Return type: { entries: MedicineCatalog[]; nameToId: Map<string, number> }

    Case 1: empty input
      inferCatalogEntriesFromLegacyMedicines([])
      → { entries: [], nameToId: Map {} }

    Case 2: single medicine, name is single lowercase word
      inferCatalogEntriesFromLegacyMedicines([{ id: 1, name: 'ibuprofen', category: 'Pain Relief' }])
      → entries[0].name === 'Ibuprofen'
      → entries[0].category === 'Pain Relief'
      → entries[0].form === null
      → nameToId.get('ibuprofen') === entries[0].id

    Case 3: two medicines with same normalized name (case+trim differ)
      inferCatalogEntriesFromLegacyMedicines([
        { id: 1, name: 'Ibuprofen 400mg', category: 'Pain Relief' },
        { id: 2, name: 'ibuprofen 400mg ', category: 'Pain Relief' },
      ])
      → entries.length === 1
      → nameToId.get('ibuprofen 400mg') is defined
      → nameToId.size === 1

    Case 4: most-common category wins (2-vs-1 vote)
      inferCatalogEntriesFromLegacyMedicines([
        { id: 1, name: 'aspirin', category: 'Pain' },
        { id: 2, name: 'aspirin', category: 'Pain' },
        { id: 3, name: 'aspirin', category: 'Allergy' },
      ])
      → entries[0].category === 'Pain'

    Case 5: category tie-break — lowest original medicine id wins
      inferCatalogEntriesFromLegacyMedicines([
        { id: 1, name: 'cetirizine', category: 'Allergy' },
        { id: 2, name: 'cetirizine', category: 'Cold' },
      ])
      → entries[0].category === 'Allergy'  (id 1 < id 2)

    Case 6: multi-word name title-cased on every word
      inferCatalogEntriesFromLegacyMedicines([{ id: 1, name: 'paracetamol extra strength', category: null }])
      → entries[0].name === 'Paracetamol Extra Strength'

    Case 7: all entries have form: null regardless of input
      → every entry in return value has form === null

    Case 8: nameToId key is lowercase trimmed version of name
      inferCatalogEntriesFromLegacyMedicines([{ id: 1, name: '  Ibuprofen  ', category: null }])
      → nameToId.has('ibuprofen') === true
      → nameToId.has('  Ibuprofen  ') === false
  </behavior>

  <implementation>
    Add the following export to src/lib/dataOps.ts (after the BackupSchema block, before exportToJSON):

    Import MedicineCatalog from './db' (add to the existing import from './db').

    Function signature:
      export function inferCatalogEntriesFromLegacyMedicines(
        medicines: { id: number; name: string; category: string | null }[]
      ): { entries: MedicineCatalog[]; nameToId: Map<string, number> }

    Algorithm (mirrors db.version(3) upgrade, lines 117–181 of src/lib/db.ts):
    1. Build a Map keyed by normalized name (name.trim().toLowerCase()).
       Each value tracks: the raw medicines in that group, and a frequency Map of category → count.
    2. For each medicine: compute normalized key; push to group; increment category frequency count.
    3. For each group (in insertion order → preserves lowest-id tie-break):
       a. title-case: split on /\s+/, capitalize first char of each word, rejoin with ' '
       b. most-common category: iterate the frequency map; track the entry with the highest count;
          for ties, compare the lowest original medicine id in that category's group
          (same tie-break as db.version(3): find(m => m.category === cat)?.id)
       c. catalogId = auto-incremented integer starting at 1
       d. createdAt = updatedAt = new Date().toISOString()
       e. form: null, notes: null
    4. Build nameToId Map: normalized name → catalogId.
    5. Return { entries, nameToId }.

    Do NOT use any Dexie calls — this is a pure synchronous function.
    Do NOT default-export; use named export only.
  </implementation>
