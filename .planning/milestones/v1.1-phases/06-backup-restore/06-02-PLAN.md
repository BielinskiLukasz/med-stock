<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User filesystem → browser | User-selected JSON file is untrusted input; content is unknown until parsed |
| Parsed JSON → Zod gate | Raw parsed object crosses into validated BackupData / LegacyBackupData only after safeParse succeeds |
| Validated data → Dexie transaction | All DB writes happen inside a single transaction; if any write fails the DB rolls back |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-01 | Tampering | importFromJSON / raw JSON input | medium | mitigate | BackupSchema.safeParse runs before any DB write; invalid JSON or schema mismatch throws before the transaction opens |
| T-06-02 | Tampering | importFromJSON / old-format path | medium | mitigate | LegacyBackupSchema.safeParse validates legacy medicines before inferCatalogEntriesFromLegacyMedicines is called; a second validation gate before DB write |
| T-06-03 | Tampering | ImportJSONSection / AlertDialog | low | mitigate | AlertDialog is shown before import, warning user that all current data will be replaced; user must click Import to proceed |
| T-06-04 | Denial of Service | importFromJSON / large file | low | accept | Browser sandbox limits memory; local app with no network vector; no fix required |
| T-06-SC | Tampering | npm package installs | high | mitigate | No new packages installed in this phase — no supply chain exposure |
</threat_model>
