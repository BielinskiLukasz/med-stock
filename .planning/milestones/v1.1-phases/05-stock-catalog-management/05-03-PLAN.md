    - useLiveQuery(() => db.medicine_catalog.toArray(), []) — get all catalogs
    - useLiveQuery(() => db.medicines.toCollection().filter(m => m.deletedAt === null).toArray(), [searchQuery]) — get active stock entries
    
    **Step 2: In-memory join + aggregate in useMemo**
    - Build Map<catalogId, { catalog, stock[], nearestExpiryStock, totalQty, status }>

    - Apply sort per D-04
    
    **Step 3: Filter semantics (D-03)**
    - **Category filter:** catalog.category in selectedCategories (or category is null and "No category" selected per D-05)
    - **Location filter:** catalog has at least one active stock entry in ANY of selectedLocations (match-any, not match-all)
    - **Status filter:** aggregate status in selectedStatuses

    **Step 4: Sort options (D-04)**
    - **Name:** sort by catalog.name lexicographically
    - **Expiry:** sort by nearest-expiry stock entry's expiryDate (per catalog aggregates)
    - **Category:** sort by catalog.category
    - **Status:** sort by aggregate status (e.g., Expired < Expiring < Active)
