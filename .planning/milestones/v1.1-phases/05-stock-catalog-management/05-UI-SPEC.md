# Phase 5 — UI Design Contract: Stock & Catalog Management

> Visual and interaction contract for Phase 5 frontend work. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> 
> Phase 5 replaces the flat medicines table with a two-layer catalog+stock model. New UI: catalog-first list aggregation, two-step add flow (search → create catalog → stock fields), detail screen with stock entries list, inline catalog edit, bottom-sheet stock edit, and split/move actions.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--background` (white in light, dark gray in dark mode) | Page backgrounds, dominant surfaces |
| Secondary (30%) | `--card` + `--secondary` (light gray in light, darker in dark) | Form inputs, card backgrounds, filter chips |
| Accent (10%) | `--primary` (dark blue: 222.2 47.4% 11.2%) | Primary action buttons, selected form focus ring |
| Destructive | `--destructive` (red: 0 84.2% 60.2%) | Delete/soft-delete buttons only |

**Accent reserved for:**
- Primary action button ("Add stock", "Create catalog", "Save" in forms)
- Form focus ring (outline on input/select/textarea when focused)
- Selected filter chip background (when active)

**Never use accent for:** secondary buttons, badge backgrounds (use semantic colors from `--secondary`), or informational text.

**Success feedback:** Use green semantic color (same as v1.0 Active status: `bg-green-100 text-green-800` light; adjusted for dark mode)

### Focal Points & Accessibility

**List View (`/medicines`):**
- Primary focal point: **MedicineCardAggregate** (catalog name card) — most prominent element; displays catalog name, status badge, and aggregate quantity. Clicking card navigates to detail view. No additional visual emphasis needed beyond standard card styling (shadow, rounded corners).

**Detail View (`/medicines/:catalogId`):**
- Primary focal point: **Catalog header** with catalog name + edit icon — positioned at top of screen. Catalog name uses Heading typography (20px, semibold, 1.2 line-height). Edit icon opens CatalogEditSheet on click.
- Secondary focal point: **Add Stock button** or "No stock" empty state CTA (bottom of screen or prominent below header).

**Add Flow (`/medicines/new`):**
- Step 1 (Search) — Primary focal point: **CatalogSearchAutocomplete input field** — placed at top with autofocus on screen load. Input field uses medium visual weight (focus ring in accent color).
- Step 2 (Create Catalog) — Primary focal point: **Catalog name input field** — pre-filled with user-typed name. Focused on step transition; user ready to select category.
- Step 3 (Stock Form) — Primary focal point: **Quantity input field** — first form field; user enters quantity immediately after catalog selection/creation.

**Icon Action Accessibility:**
- Stock entry row action icons ("Open box", "Move/Split") are **icon-only buttons** with the following accessibility contract:
  - Each icon button includes `aria-label` attribute with descriptive text: `aria-label="Open box"` and `aria-label="Move or split stock entry"`
  - Icons use lucide-react (e.g., `<Button variant="ghost" size="sm" aria-label="Open box"><Package className="h-4 w-4" /></Button>`)
  - No visible text label on the icon (space-constrained card layout)
  - On hover, browser-native tooltip (via title attribute) or custom Tooltip component shows action label for desktop users
  - Mobile users access action via VoiceOver / TalkBack using aria-label; icon clickable area at least 44px × 44px per WCAG touch target guidance

## Interaction Details

### Add Flow (D-06)

Three internal steps within `/medicines/new` (no new routes):

1. **Search** — Catalog autocomplete
   - Focus → show all catalogs
   - Type → filter by substring (case-insensitive)
   - 0 matches → show "Create '[typed name]'" option
   - Select existing → advance to Step 3 (StockForm) with catalogId pre-filled
   - Select "Create..." → advance to Step 2 (CatalogForm) with name pre-filled

2. **Create Catalog** — Only shown if user selects "Create..."
   - Form: name (pre-filled), category (required), form (optional)
   - Back arrow discards, returns to Step 1
   - Submit → store catalog, advance to Step 3

3. **Stock Form** — Always shown after catalog is selected/created
   - Form: quantity, expiryDate, location, pao (optional), notes (optional)
   - Back arrow discards stock form data, returns to Step 1
   - Cancel button exits to `/medicines`
   - Submit → store stock entry, navigate to detail view (or list view, TBD by planner)

### Detail View (D-11, D-13)

- URL: `/medicines/:catalogId` (not `:id`)
- Header: catalog name + edit icon
- Edit icon → opens CatalogEditSheet (D-13)
- Content: list of all active stock entries
- Each stock entry row: quantity + unit, expiry date, location, status badge, edit action
- Row click → opens StockEditSheet pre-filled with entry data
- Stock entry actions:
  - "Open box" → creates new entry (qty=1, openedDate=today, same location), decrements original by 1
  - "Move/Split" → opens MoveStockSheet, user picks quantity + destination, creates new entry, decrements original

### Catalog Edit (D-13)

- Triggered from detail header edit icon
- Bottom sheet or inline editor
- Fields: name, category, form, notes
- Submit → updates catalog in `medicine_catalog` table (affects all linked stock entries on re-render)

### Stock Edit (D-14)

- Triggered from StockEntryCard click or edit action
- Bottom sheet
- Pre-filled with current entry values
- Fields: quantity, expiryDate, location, pao, paoUnit, notes
- Submit → updates `medicines` (stock) table
- Cancel → discards edits, closes sheet

### List View (D-01, D-02)

- Two-query pattern: `useLiveQuery` for catalogs, `useLiveQuery` for active stock entries
- `useMemo` computes per-catalog aggregates: nearest-expiry status + total quantity
- Each MedicineCardAggregate displays: catalog name, status badge, quantity summary
- Link navigates to `/medicines/:catalogId`
- Filter chips adapted per D-03 (location match-any, category on catalog, status on aggregate)
- Sort options per D-04 (name on catalog, expiry on nearest-stock, category on catalog)
