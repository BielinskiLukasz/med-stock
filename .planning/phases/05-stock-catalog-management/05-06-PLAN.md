    Actually, looking at Plan 4 (stockOps.ts), moveStock doesn't explicitly set openedDate on the new entry — it copies from original. For "Open box", we want openedDate=today on the NEW entry. Let me reconsider:

    Option A: Modify moveStock to accept openedDate param for new entry
    Option B: Have "Open box" manually call db.medicines.add with openedDate=today instead of calling moveStock

    I'll go with Option B for simplicity: "Open box" is a special case that directly inserts a new entry with openedDate=today, then decrements the original. This keeps the logic simple and doesn't require modifying Plan 4.

    Pseudo-code for "Open box":
    ```typescript
    async function handleOpenBoxClick(stock: Medicine) {
      try {
        const now = new Date().toISOString().split('T')[0]  // YYYY-MM-DD
        const today = now
        
        // Insert new entry with openedDate=today
        await db.transaction('rw', db.medicines, db.history, async () => {
          const newId = await db.medicines.add({
            catalogId: stock.catalogId,
            quantity: 1,
            quantityUnit: stock.quantityUnit,
            expiryDate: stock.expiryDate,
            openedDate: today,
            pao: stock.pao,
            location: stock.location,
            manualStatus: null,
            notes: stock.notes,
            createdAt: now,
            updatedAt: now,
            deletedAt: null,
          })
          
          // Decrement original
          await db.medicines.update(stock.id, {
            quantity: (stock.quantity ?? 0) - 1,
            updatedAt: now,
          })
          
          // Record history
          const newStock = await db.medicines.get(newId)
          if (newStock) {
            await addMedicineHistory(newStock, catalog.name, 'created')
          }
          
          const updated = await db.medicines.get(stock.id)
          if (updated) {
            await updateMedicineWithHistory(stock.id, stock, { quantity: (stock.quantity ?? 0) - 1, updatedAt: now }, catalog.name)
          }
        })
        
        toast.success('Box opened')
      } catch (err) {
        console.error('Failed to open box:', err)
        toast.error('Failed to open box. Please try again.')
      }
    }
    ```

    This keeps "Open box" simple and avoids modifying Plan 4.
