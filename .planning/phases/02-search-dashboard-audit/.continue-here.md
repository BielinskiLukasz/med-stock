## Critical Anti-Patterns (do NOT repeat these)

- **ZUSTAND_V5_SHALLOW**: Use `useShallow(selector)` wrapper — NOT `useStore(selector, shallow)`. The second-arg API was removed in Zustand v5. This caused a runtime error in Phase 1.
- **DEXIE_NULL_KEY**: Do not query Dexie with `equals(null)` — null is not a valid IndexedDB key. Filter nulls in JS after `toCollection()` instead (see TrashScreen pattern).
- **SHADCN_CLI_PATH**: The shadcn CLI may place files in the wrong `@/` directory on Windows. Verify the output path before assuming the file was created correctly; create manually if needed.
